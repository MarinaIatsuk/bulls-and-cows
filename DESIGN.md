# Design decisions

## Data structures

`GameState` в `src/state.ts` — неизменяемый объект с настройками, секретом,
массивом попыток, статусом и временными метками. Каждая попытка создаёт новое
состояние и новый массив истории, поэтому старые состояния не меняются.

`ScoreRecord` в `src/records.ts` хранит систему счисления, длину секрета,
количество попыток и затраченное время. Рекорды сортируются по числу попыток,
затем по времени и сохраняются отдельно для каждой комбинации base/length.

## Algorithms

### `generateSecret`

Функция создаёт пул доступных цифр и на каждом шаге выбирает одну цифру через
переданную функцию `random`. Выбранная цифра удаляется из пула созданием нового
массива. Инъекция `random` позволяет проверять генерацию детерминированными тестами.
Ведущий ноль допустим.

### `evaluateGuess`

Сначала сравниваются цифры на одинаковых позициях и считаются bulls. Затем
цифры из правильных позиций исключаются. `reduce` сопоставляет оставшиеся цифры
попытки с оставшимися цифрами секрета и считает cows, не используя цифру повторно.
Hex-цифры сравниваются без учёта регистра.

### `countPossibleSecrets`

Используется рекуррентная формула `P(base, length) =
base * P(base - 1, length - 1)` с базовым случаем `P(base, 0) = 1`.
Результаты подзадач хранятся в `Map` по паре «оставшаяся длина / доступные цифры».

## Complexity

- `generateSecret`: `O(length × base)` времени из-за фильтрации пула при каждом
  выборе; `O(base + length)` дополнительной памяти.
- `evaluateGuess`: `O(length²)` времени из-за поиска совпадений в оставшихся
  массивах; `O(length)` памяти.
- `isValidGuess`: в среднем `O(length)` времени и `O(length)` памяти для
  массива символов и `Set` уникальности.
- `countPossibleSecrets`: `O(length)` времени и памяти при первом вызове пары
  параметров; `O(1)` при повторном попадании в кэш.

## Clean code

- Игровая логика отделена от DOM: чистые функции находятся в `src/game.ts`.
- `createDigitValidator` возвращает функцию-предикат и повторно используется
  при проверке и фильтрации ввода.
- Функции проверяют некорректные аргументы в начале, до основной логики.
- `src/state.ts` обновляет состояние иммутабельно через spread и новые массивы.
- UI обновляет DOM с помощью `createElement`, `textContent` и `replaceChildren`,
  не используя `innerHTML`.
