# Bulls and Cows

Небольшая браузерная игра Bulls and Cows: угадайте секретный код из уникальных цифр. После каждой попытки игра сообщает количество **bulls** — цифр на правильных позициях — и **cows** — цифр, которые есть в секрете, но стоят не на своих местах.

Игра работает в браузере, не требует сервера или внешнего API. Рекорды сохраняются локально в браузере.

## Возможности

- Выбор системы счисления: двоичная, восьмеричная, десятичная или шестнадцатеричная.
- Выбор длины секрета от 2 до 6 цифр; длина ограничена количеством доступных цифр выбранной системы.
- Секрет состоит из уникальных цифр; ведущий ноль допустим.
- Фильтрация недопустимых символов и поддержка верхнего/нижнего регистра для hex-цифр.
- История попыток с результатами bulls/cows; повторные попытки не добавляются.
- Таймер раунда и подсчёт количества попыток.
- Таблица лучших результатов, отдельная для каждой длины и системы счисления; данные сохраняются в `localStorage`.
- Новая игра запускается без перезагрузки страницы.

## Технологии

- TypeScript
- Vite
- Vitest
- ESLint и Prettier
- Husky и lint-staged

Требуется Node.js `20.19+` либо `22.13+` (подойдёт также актуальная версия Node.js 24).

## Локальный запуск

Установите зависимости из lock-файла:

```bash
npm ci
```

Запустите Vite dev server:

```bash
npm run dev
```

Откройте адрес, напечатанный Vite в терминале. Обычно это `http://localhost:5173/`.

Для production-сборки и локального просмотра собранной версии:

```bash
npm run build
npm run preview
```

## Проверки

```bash
npm test          # тесты Vitest
npm run test:watch
npm run lint       # ESLint
npm run typecheck  # проверка типов TypeScript
npm run format     # форматирование Prettier
npm run build      # проверка типов и production-сборка Vite
```

Перед push Husky запускает `npm test`; перед commit `lint-staged` проверяет изменённые файлы.

## Структура проекта

- `src/game.ts` — игровое ядро: генерация секрета, проверка попыток, подсчёт bulls/cows и количества возможных секретов.
- `src/state.ts` — неизменяемые переходы состояния раунда и история попыток.
- `src/records.ts` — типы и функции для проверки, ранжирования и форматирования рекордов.
- `src/main.ts` — интерфейс браузерной игры и работа с DOM и `localStorage`.
- `tests/` — unit-тесты игрового ядра, состояния и рекордов.
- `style.css` — стили интерфейса.
- `DESIGN.md` — описание решений, алгоритмов и их сложности.

Игровые функции не зависят от DOM. Интерфейс создаёт элементы через DOM API и не использует `innerHTML` для динамического содержимого.

## Как играть

1. Выберите систему счисления и длину секрета.
2. Нажмите **Start game**.
3. Вводите код из допустимых, неповторяющихся цифр.
4. Используйте подсказки bulls/cows, чтобы найти секрет. Ограничения на количество попыток нет.
5. После победы результат попадёт в таблицу рекордов.
